# Visual Defect Detection Pipeline using MobileNetV2

This repository contains an end-to-end deep learning pipeline for binary image classification (**Reference** vs. **Defect**) using MobileNetV2 with Transfer Learning and 5-Fold Stratified Cross-Validation.

## Features
- **Model Architecture:** MobileNetV2 + Custom Dense Classifier Head
- **Validation:** 5-Fold Stratified Cross-Validation with dynamic threshold optimization
- **Deployment:** Interactive Streamlit web interface for real-time image inference
